# 人材紹介 免許申請書類 無料作成ツール 要件定義

作成日: 2026-09-29
対象: 求職者送客クラウド（soukyaku-cloud.com）配下 `/license/` に設置する無料ツール
実装: `license-tool/`（静的HTML + ブラウザ内生成、リード受付はGAS）

## 1. 目的と背景

- 有料職業紹介事業の許可申請書類を「無料・セルフサーブ」で作成できるツールを提供し、免許取得前の新規エージェントを入口で押さえる。
- 先行事例: ROXX（旧SCOUTER）「レッツ人材紹介」（2018年8月）。リリース2ヶ月で累計100社、月間新規許可数の約6割が利用。現在は休眠と見られ、無料セルフサーブ型の席は空いている。
- 競合状況: LegalScript（有料 21,700円/件）、社労士系（相談無料・代行有料）、労働局（白紙様式のみ）。完全無料の作成ツールは他にない。

## 2. ジャーニーとドメイン方針

- ジャーニー: 免許申請 → 許可待ち（2〜3ヶ月） → 求職者送客クラウドで小さく試す → 決定が出たら求職者送客の窓口へ。
- ドメイン: 求職者送客クラウド配下のサブディレクトリ `/license/`。新規ドメイン・サブドメインは使わない（ROXXの launch.agent-bank.com はサービス名変更とともに消えた）。
- 送客クラウドの本体は別リポジトリの Next.js（Vercel）。本ツールは静的サイトとして別Vercelプロジェクトにデプロイし、本体側の `next.config` の rewrites で `/license/:path*` を向ける。
- 窓口とクラウドの食い合いは許容する（競合ひしめく中で自社内の食い合いは誤差）。
- 免許取得・立ち上げ系のコラムは今後クラウドの「開業・免許」カテゴリに集約する。

## 3. 画面の流れ

1. LP（`/license/`）: 「有料職業紹介の許可申請書類を無料で作成」。
2. 要件診断（5分）: 法人/個人、基準資産額、現預金、事務所形態、責任者講習の受講有無、予定領域、開業予定月。不合格は理由と提携社労士の案内で終了。
3. 書類入力: 同じ情報（会社名・住所・責任者）は一度だけ聞く。ステップ形式。
4. 受け取り画面: メールアドレスを入力して書類を受け取る。任意チェック「免許取得から月商300万円までのロードマップ（無料相談付き）を受け取る」。
5. マイページ相当（ローカル保存）: 進捗TODO、開示ページの発行、「許可が出た」ボタン。

## 4. 生成する書類

| 書類 | 生成方式 | 備考 |
|---|---|---|
| 様式第1号 職業紹介事業許可申請書（第1面・第2面） | 公式Word（労働局配布）に差し込み | 令和7年5月版 |
| 様式第2号 有料職業紹介事業計画書 | 公式Wordに差し込み | 個人事業のみ資産欄 |
| 様式第3号 届出制手数料届出書 | 公式Wordに差し込み | 「別紙手数料表による」 |
| 手数料表（様式例第3号-1 一般登録型） | 公式Wordに差し込み | 料率・負担者・返戻金 |
| 業務の運営に関する規程（様式例第1号） | 公式ひな形に差し込み | 取扱職種の範囲等 |
| 個人情報適正管理規程 | ひな形に差し込み | 職員の範囲・責任者 |
| 求人者・求職者への明示書面 | ひな形に差し込み | 開示ページと共通 |
| 添付書類チェックリスト | HTML/印刷 | 法人・個人で分岐 |

- 生成はすべてブラウザ内で行い、住民票・決算・履歴書などの個人情報はサーバーに送らない。
- 保存するのは会社名、メール、スコア項目（領域、予定求人数、予定求職者数、手数料率、開業予定月、所在地、集客経路）のみ。

## 5. リード選別（スコア）

- 要件診断と様式第2号の入力から自動取得。
- 最優先: 領域が20代・未経験・第二新卒・高卒／集客経路が未定または自社SNS予定／開業予定が3ヶ月以内。
- ハイクラス・専門職特化は送客の供給と合わないためメールのみ。

## 6. 許可までのメール設計

- Day 0: 書類一式（ダウンロードリンク）とTODOリスト。
- Day 1〜3: ロードマップ第1章「免許待ちの2ヶ月でやること」。求人DB比較（agent bank / circusAGENT / 転職AGENT Navi）を正直に載せ、集客経路の決め方の中でクラウドを選択肢として出す。
- Day 7: 「労働局に提出しましたか」＋補正でよく指摘される点。
- Day 14〜: 求人開拓テンプレ、面談スクリプトなど週1。
- 許可ボタン押下当日: お祝い＋初月の送客枠＋スターターキット。営業電話はこの後の1本のみ。
- 許可ボタン未押下: 開業予定月の前後に1回確認。
- 許可から60〜90日: 「決定は出ましたか」。面談数が増えている会社に窓口を案内。

## 7. TODOリスト（マネーフォワード会社設立方式）

```
□ 職業紹介責任者講習を予約する
□ 労働局に申請書を提出する（登録免許税9万円・収入印紙5万円）
□ 補正連絡に対応する
□ 求人DBを契約する（他社比較を正直に掲載）
□ 求職者の集客経路を決める（自社集客／送客サービス／求人媒体）
□ 手数料表・運営規程を公開する（→ 開示ページを発行）
□ 許可通知を受け取る（「許可が出た」ボタン）
□ 開業初月の求人開拓を始める（スターターキット）
```

## 8. 法定開示ページ（被リンク施策）

- 特商法表記ジェネレーターの人材紹介版。生成した手数料表・運営規程・個人情報適正管理規程・許可番号・実績情報（年1回）を `soukyaku-cloud.com/agency/{slug}/` で公開。
- 相手は自社サイトのフッターや求人票にURLを貼るだけで明示義務を満たせる。工数ゼロで自然な被リンクが発生する。
- 利用規約でのリンク強制はGoogleのスパムポリシー違反になるため行わない。
- 第2弾で実装（要サーバー側の保存。第1弾はローカル生成のみ）。

## 9. MVPの切り方

- 第1弾: 要件診断、書類生成、メール受け取り、TODOリスト、Day 0〜14メール。PR TIMES配信可能な状態。
- 第2弾: 「許可が出た」ボタンの永続化、開示ページ発行、スコアの営業通知。
- 第3弾: ロードマップ全章、スターターキット、社労士紹介の紹介料設計。

## 10. 数字の目安

- 全国の新規許可: 月100〜150件。利用上限の目安は月50〜80社。
- 転換仮説: 最優先スコア3〜4割 × 許可到達7割 × 初月利用3割 → 月5〜10社。
- KPI: 診断完了率、書類生成完了率、メール取得率、許可ボタン押下率、許可後30日以内の利用開始率。

## 11. 維持コスト

- インフラは静的サイトのため月数千円。
- 本体は様式追随（年1〜2回）、問い合わせ対応（FAQで切る）、個人情報（保存しない設計で回避）。
- 生成物は公式様式そのものを埋める形にして、様式改定時はテンプレート差し替えで済ませる。

## 12. 法務の確認事項

- 社労士法: 書類は「利用者自身が入力して生成」、相談は「事業の立ち上げ相談」に限定。提携社労士の監修名義を取る。
- 景表法: 「3ヶ月で月商300万円」のような期限付きの成果表現は使わない。「目指す」「事例」に統一。
- 職安法: 明示義務（手数料表・運営規程・個人情報適正管理規程・取扱職種範囲）と32条の16の実績情報公開を、開示ページの必須項目にする。
- 2025年1月施行の許可条件追加（東京労働局案内）を要件診断に反映すること。

## 13. SEO

- 主要SERPはマイナビtameni、マネーフォワード、クラウドエージェント、circusAGENT、PORTERS、社労士事務所、労働局。ツールを持つサイトはない。
- ツールを linkable asset にして、社労士ブログ・HRメディア（HRog、日本人材ニュース、HRzine）からの言及を取る。PR TIMESはROXXと同じ流れ。
- 記事クラスター: 事業計画書の記入例、手数料表の書き方、運営規程ひな形、個人情報適正管理規程ひな形、責任者講習日程、都道府県別提出先、不許可事例、更新。
