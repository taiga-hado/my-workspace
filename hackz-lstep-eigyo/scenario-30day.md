### T2（2日目）
```
「営業はきつい」という言葉は、実は4種類がごちゃ混ぜになっています。

・個人宅への訪問販売
・テレアポ中心の新規開拓
・ルート営業
・法人向けのIT/SaaS営業、インサイドセールス

断られ続けるのは上の2つです。
今ご紹介している求人は一番下だけで、問い合わせのあった企業に提案する仕事です。土日休み・残業少なめで、初年度年収は500〜600万円です。
```

### T3（3日目）
```
LINEでご紹介した25歳の方は、アパレル販売からインサイドセールスに移って年収が350万→470万になりました。

やったことは3つです。
・IT/SaaSの中で、未経験OKかつ土日休みの会社に絞った
・接客の経験を「営業の言葉」に書き換えた
・面接で聞かれることを担当者と練習した

営業経験ゼロからでも、この3つで通ります。
```

### T5（5日目）
```
初年度年収500〜600万円と聞くと「インセンティブで無理に積んだ数字では？」と思われるかもしれません。

ご紹介している求人は、基本給の比率が高い会社を中心にしています。
インセンティブ比率が高すぎる会社は、売れない月の落ち込みが大きく、結局続きません。

面談では「基本給いくら／インセンティブいくら／賞与いくら」まで分けて確認できます。ここを曖昧にしたまま入社するのが一番危険です。
```


### T9（9日目）
```
ホワイトかどうかは、求人票では判断できません。
私たちが実際に見ているのは、この3つです。

・有給取得率を数字で出せるか
・残業時間の「実績値」を出せるか（規定ではなく実績）
・インセンティブ比率が高すぎないか

この3つが確認できた会社だけをご紹介しています。
「営業はブラックばかり」と思っていた方が、いちばん驚くポイントです。
```

### T12（12日目）
```
よくいただく不安をまとめておきます。

・ノルマが不安 → ノルマ比率の低い求人を選べます
・PCスキルが不安 → 入社後の研修前提の未経験枠です
・学歴が不安 → 学歴不問の求人があります
・転職回数が多い → 3回までなら未経験OK求人の大半が対象です

どれも面談で条件として伝えておけば、最初から外して求人を選べます。
```
