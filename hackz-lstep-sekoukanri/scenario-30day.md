## テキスト全文

### T2（2日目）
```
「施工管理は資格がないと無理」と思われがちですが、実際は逆です。

未経験で入社した方の多くは、資格を持たずに入って、入社後に会社負担で2級施工管理技士を取っています。
資格取得支援がある会社を選べば、受験費用も講座も会社側の負担です。

つまり、今の時点で必要なのは資格ではなく「資格支援のある会社を知っていること」です。
```

### T3（3日目）
```
LINEでご紹介した24歳の方は、フリーターから施工管理に移って年収が260万→420万になりました。

特別なことは何もしていません。
・未経験OKで、資格取得支援がある会社に絞った
・書類の書き方を担当者と直した
・現場の種類（ビル/プラント/公共工事）を選んだ

この3つだけです。逆に、ここを自分ひとりで判断すると、入ってから「思っていた現場と違う」になります。
```

### T5（5日目）
```
施工管理の仕事を「現場で汗をかく仕事」だと思っている方が多いのですが、実際の中身は管理と書類です。

・工程表をつくる
・進捗を確認して写真を撮る
・職人さんと段取りを合わせる
・図面や書類をまとめる

体力勝負ではないので、前職が飲食や販売の方でも続けられます。
残業なしで回っている会社は、この「段取り」が上手い会社です。求人票からは分かりませんが、担当者は知っています。
```

### T7（7日目・田中亜美名義）
```
名前さん、担当の田中です。返信は不要です。

施工管理の求人は、年度や決算期の区切りで採用計画が切り替わります。
「未経験OK・年収500万円以上」の枠は、埋まった時点で静かに閉じます。

今すぐ転職しなくても大丈夫です。ただ、条件の確認だけは早い方が損をしません。
今の経歴で狙える会社と年収レンジだけ出しておけば、動きたくなったときにすぐ進められます。

面談はスマホから30分、平日夜・土日も対応しています。予約枠だけ置いておきます。
```

### T9（9日目）
```
求人票の「週休2日制」は、土曜出勤がある会社でも書けます。

年間休日で見ると差がはっきりします。
・年間休日105日前後 … 土曜は基本出勤
・年間休日120日 … 土日祝休み＋夏季冬季

同じ施工管理でも、この差で生活がまるごと変わります。
LPでご紹介した大手ゼネコンの求人は年間休日120日、年収は420万→680万の実例です。
```

### T12（12日目）
```
よくいただく不安をまとめておきます。

・体力に自信がない → 施工管理は現場作業ではなく管理と書類が中心です
・転勤が不安 → 地域限定・転勤なしの求人を優先してご紹介できます
・学歴が不安 → 学歴不問の未経験枠があります
・転職回数が多い → 施工管理は人手不足のため、回数はほぼ問われません

どれも面談で条件として伝えておけば、最初から外して求人を選べます。
```

### T18（18日目・田中亜美名義）
```
名前さん、田中です。

転職で失敗する一番のパターンは、「未経験でも入れる会社」に入れたのに、現場と働き方が合わずに1年以内に辞めてしまうことです。
これはご本人の問題ではなく、会社と現場の選び方の問題です。

私たちがやるのは、求人を大量に送ることではありません。
1,000人以上の認定キャリアアドバイザーから、名前さんの条件に一番強い1名を選ぶところまでです。
そこから先はその担当者が、書類から面接、年収交渉まで担当します。入社まで完全無料です。
```

### T25（25日目）
```
ここまで読んでいただいて、まだ動いていない方に一度だけお伝えします。

施工管理は、30代からでも入れます。ただ、未経験で入るなら20代のうちが圧倒的に有利です。
理由は単純で、未経験採用は「これから資格を取って育てる」前提の採用だからです。

いま面談を済ませておけば、条件に合う求人が出たタイミングでご連絡できます。
動くかどうかは、そのときに決めていただければ大丈夫です。
```
