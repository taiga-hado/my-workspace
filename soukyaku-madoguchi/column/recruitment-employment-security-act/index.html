職業安定法の遵守ポイント｜人材紹介の求人票・広告表現で違反しないための実務

公開日：2026.07.22
読了時間：約10分
カテゴリ：用語解説

人材紹介事業は職業安定法（職安法）に基づく厚生労働大臣の許可事業であり、求人票の記載内容・広告表現・求職者情報の取扱いのすべてが法規制の対象です。2022年10月の改正で募集情報等提供事業者に対する規制が強化され、2024年4月の改正では労働条件明示義務の項目がさらに追加されるなど、コンプライアンス要件は年々厳格化しています。

本記事では、人材紹介事業者が求人票や広告表現で押さえるべき禁止事項・明示義務、求職者情報の取得・利用における同意取得の実務、そして行政指導を避けるための社内チェック体制と教育設計を、実務レベルで整理します。

職業安定法の基本と2024年改正で強化された明示義務

職業安定法は、求職者保護と労働市場の適正化を目的とした法律です。人材紹介事業者は「有料職業紹介事業」の許可を取得したうえで、求人企業と求職者の双方に対して法令上の義務を負います。

2022年10月改正の主なポイント：

  • 募集情報等提供事業者の届出制導入：求人メディア・アグリゲーション型サイトが規制対象に
  • 的確表示義務：求人情報を「虚偽・誤解を与える表示」にしてはならない義務
  • 個人情報の適正な取扱いの明文化：求職者から得た情報の目的外利用を明示的に禁止
  • 苦情処理体制の整備義務：求職者・求人者からの苦情に対応する仕組みを社内に持つ

2024年4月改正で追加された労働条件明示義務（労働基準法との連動）：

  • 就業場所・業務内容の「変更の範囲」：入社後に配置転換で発生し得る場所・業務まで明示
  • 更新上限の有無・内容：有期雇用の場合の通算契約期間や更新回数の上限
  • 無期転換申込機会・無期転換後の労働条件：5年通算での無期転換ルール適用時の条件

人材紹介事業者は、求人企業から取得した情報を求職者に伝達する立場です。求人企業側で明示漏れがあった場合も、紹介事業者として「明示できているか」を確認する責務があるため、求人票フォーマットのアップデートが必須です。

実務上の注意：2024年改正以降、求人企業から「就業場所：東京本社」とだけ記載された求人票を受領しても、そのまま求職者に提示すると明示義務違反となる可能性があります。「変更の範囲：会社が定める事業所」など、変更の可能性まで確認する運用フローが必要です。

求人票・広告で禁止される表現と誇大表示のNG例

職業安定法第5条の4および指針で禁止されている表現の具体例：

1. 賃金に関する誇大・不正確な表示

  • 「月収50万円可能！」（実際は歩合込みの理論値で、固定は月20万円）
  • 「年収700万円〜」（実際の最低ラインが400万円）
  • 固定残業代を含む金額を「基本給」として表示

賃金は「基本給」「固定残業代（時間数・金額）」「その他手当」を分けて表示する必要があります。月給の「〜万円」表記は下限値を明示しないと違反リスクが高まります。

2. 職種・業務内容の実態と異なる表示

  • 「Webマーケター募集」（実態はテレアポ営業）
  • 「エンジニア」（実態はSES契約先での事務補助）
  • 「マネジメント業務」（実態は現場作業員）

3. 雇用形態の曖昧な表示

  • 「正社員登用あり」を強調しつつ、実態が業務委託や派遣
  • 試用期間中の労働条件（賃金・雇用形態）を明示しない

4. 実在しない求人・古い求人の掲載

すでに充足した求人を掲載し続けて応募を集める「釣り求人」は、的確表示義務違反として行政指導の対象になります。求人メディアや自社サイト掲載分は、月次以上の鮮度管理が必要です。

5. 差別的表現

  • 性別限定（男女雇用機会均等法にも抵触）
  • 年齢制限（雇用対策法の例外事由なしで年齢を限定）
  • 国籍・出身地による制限

「若手が活躍中」「20代中心の職場」といった表現も、年齢を実質的に限定する意図と解釈される可能性があり、注意が必要です。

求職者情報の取得・利用における同意取得の実務

求職者から取得する情報は、個人情報保護法と職業安定法の両方の規制を受けます。人材紹介の場合、特に以下の観点が実務上のポイントです。

1. 収集目的の明示

求職登録の入口（LP・登録フォーム）で、「取得した情報を職業紹介の目的で利用すること」「求人企業への提供範囲」を明示する必要があります。プライバシーポリシーへのリンクだけでは不十分で、登録画面上に要約を掲載するのが望ましい運用です。

2. 求人企業への情報提供時の同意

  • 推薦時に企業へ提出するレジュメ・職務経歴書の内容は、求職者本人の事前同意が必須
  • 「複数企業に一括推薦」する運用の場合、企業ごとに同意を取るのが安全
  • 企業名を伏せた状態でのスカウトメール送信も、内容によっては情報提供と解釈される

3. 取得してはならない情報

職業安定法指針で、業務遂行上の必要性がない限り取得を禁止されている情報：

  • 本籍・出生地
  • 家族の職業・収入・資産
  • 住宅状況・生活環境
  • 思想・信条・宗教
  • 労働組合への加入状況

キャリアカウンセリング時の雑談で聞き出してしまうケースが実務上のリスクです。CA向けのヒアリングスクリプトから該当項目を排除し、聞かないための設計が必要です。

4. 利用停止・削除への対応

求職者から「登録抹消」「情報削除」の申請があった場合、遅滞なく（実務上は2週間以内が目安）対応する体制が必要です。CRM・ATS上でのデータ削除フローを明文化しておきます。

行政指導を避けるための社内チェック体制と教育設計

行政指導は、労働局からの「文書指導」→「改善命令」→「事業停止命令」→「許可取消」の段階で進みます。実務上の多くは苦情申立てや定期監査を契機に始まるため、日常的な予防体制が重要です。

1. 求人票のダブルチェック体制

  • 営業（RA）が受注した求人情報を、コンプライアンス担当または管理職が二次チェック
  • 賃金・業務内容・変更の範囲・固定残業の記載を必須項目化
  • チェックリストを求人票フォーマットに埋め込む

2. 広告・LPの表現レビュー

SNS広告・リスティング・LPは、マーケ担当が独自に運用するとコンプライアンス視点が抜けやすい領域です。公開前レビュー（法務またはコンプライアンス担当）を必須プロセスに組み込みます。

3. CA・RAの定期教育

  • 入社時オンボーディングでの職安法研修（2〜3時間）
  • 年1回以上の法改正フォロー研修
  • 過去の行政指導事例・他社の違反事例の共有

4. 苦情処理窓口の設置と記録

求職者・求人企業からの苦情を受け付ける窓口を明示し、対応記録を残します。労働局の監査時に「苦情処理台帳」の提示を求められるケースがあるため、Excelや専用ツールで一元管理しておきます。

集客チャネル側のリスク：自社で運用するSNS広告・アフィリエイト・比較サイト経由の集客において、パートナー側が誇大表現を使うケースも法的責任が及ぶ可能性があります。外部提携先の広告クリエイティブも定期的に確認する運用が必要です。

5. 業界団体・行政情報のウォッチ

厚生労働省・全国民営職業紹介事業協会（民紹協）・人材サービス産業協議会（JHR）の発信を定期チェック。改正情報や指導事例をタイムリーに把握することが、リスクの先読みに直結します。

SUMMARY

  • 職業安定法は2022年・2024年の改正で明示義務・的確表示義務が強化。就業場所や業務内容の「変更の範囲」まで明示が必要
  • 賃金の誇大表示、実態と異なる職種名、充足済み求人の掲載などが的確表示義務違反となり行政指導の対象になる
  • 求職者情報は取得目的の明示・企業推薦時の同意取得が必須。本籍や家族状況など5項目は原則取得禁止
  • 求人票のダブルチェック、広告表現の法務レビュー、CAへの年1回研修、苦情処理台帳の整備が実務の柱

コンプライアンスを担保しつつ集客規模を拡大したい場合

職業安定法の遵守は事業許可の維持に直結する重要事項ですが、コンプライアンス体制を厳格にすればするほど、求人票の受託基準や広告表現の制約が増え、自社集客の効率が下がるジレンマが生じます。特に若手求職者向けのSNS広告は表現規制が厳しく、社内で運用しきれずCPAが高騰するケースが少なくありません。集客チャネルの一部を外部化し、法令遵守のコストと責任を分担する選択肢が現実的です。

「求職者送客の窓口」は、SNSを軸とした独自集客と事前カウンセリングを内製し、職業安定法・個人情報保護法に準拠した運用のうえで求職者をエージェント様に送客する着座成果報酬型サービスです。初期費用0円・月額費用0円・面談着座率80〜90%で、広告表現のコンプライアンスリスクを社外に切り出しながら、第二新卒・若手未経験層の母集団を安定的に確保できます。
