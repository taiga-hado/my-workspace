有料職業紹介の許可申請で補正になりやすい15の点

不許可になる申請はまれですが、補正（修正依頼）はよくあります。補正のたびに1〜4週間延びるので、提出前につぶしておくのが最も効く時短です。労働局から指摘されやすい点を、書類ごとに15項目にまとめました。

様式第1号（申請書）

  1. 住所表記の不一致：申請書・登記事項証明書・住民票・賃貸借契約書で「1丁目1番1号」「1-1-1」「ビル名の有無」が揃っていない。→ すべて登記事項証明書の表記に統一する。
  2. 役員の記載漏れ：監査役や、登記上残っている役員が抜けている。→ 登記事項証明書の役員欄をそのまま転記する。
  3. 抹消の方法：「無料」「更新」の文言を消し忘れている、または労働局の指定（二重線）と違う。→ 窓口の指示に合わせる。
  4. 申請日の記載：講習受講日より前の日付になっている。→ 受講日以降にする。

添付書類

  1. 定款の事業目的：「有料職業紹介事業」がない。→ 目的変更の登記をしてから申請（登録免許税3万円、2〜3週間）。
  2. 履歴書の空白期間：役員の履歴書に説明のない空白がある。→ 「求職活動」「家事」など事実を記載する。
  3. 住民票の記載事項：本籍地の記載がない、マイナンバーが記載されている。→ 本籍あり・マイナンバーなしで再取得。
  4. 納税証明書の種類：「その1」しかない。→ 法人税の「その2（所得金額）」を取得。
  5. 登記事項証明書の期限：発行から3ヶ月を超えている。→ 再取得。

事業所

  1. レイアウト図の不足：面談スペースと書類の保管場所（施錠キャビネット）が図にない。→ 図に書き込む。パーテーションの位置も。
  2. 使用権の証明：賃貸借契約書の使用目的が「住居」になっている、契約者が代表者個人になっている。→ 事務所使用の承諾書や転貸承諾書を追加。

資産要件

  1. 繰延資産・営業権の控除漏れ：純資産だけで500万円を判定している。→ 資産−（負債＋繰延資産＋営業権）で再計算（計算方法）。
  2. 現預金の証明：決算日から時間が経ち、現預金150万円の確認資料を求められる。→ 申請日直近の残高証明書を用意。

規程・手数料表

  1. 書類間の数字のズレ：手数料表の料率と業務運営規程の手数料条項、返戻金の条件が一致していない。→ 同じ入力から作る（無料ツールは自動で揃います）。
  2. 個人情報適正管理規程の必須4項目：教育・研修や苦情処理の項目がない。→ 必須4項目を追加。

提出前チェックリスト

  • 住所表記が全書類で登記どおりになっている
  • 役員全員の住民票・履歴書があり、住所が一致している
  • 定款の事業目的に「有料職業紹介事業」がある
  • 講習の受講日が申請日より前で、5年以内
  • 基準資産額（繰延資産・営業権控除後）500万円以上、現預金150万円以上
  • レイアウト図に面談スペースと保管場所がある
  • 手数料表・規程・明示書面の料率と返戻金が一致している
  • 登録免許税9万円の領収証書と収入印紙5万円を用意した
  • 原本1部と写し2部（労働局の指定部数）を揃えた

よくある質問

補正の連絡はどう来ますか

労働局の担当者から電話または書面で来ます。平日日中に電話に出られる体制にしておき、申請書類の控えを手元に置いてください。

補正に応じないとどうなりますか

期限内に対応しないと申請が取り下げ扱いや不許可になることがあります。納付した登録免許税は戻りません。

補正で許可日は遅れますか

補正が翌月にずれ込むと許可日も1ヶ月遅れることがあります。月の前半に提出し、補正に即日対応するのが最短です。
