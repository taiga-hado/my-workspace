# CA向け初回オンボーディング　進行台本

窓口担当（佐伯・松本）用。中途（第二新卒）／新卒のどちらも同じ流れで進む。
スライドは `chuto.pdf` ／ `shinsotsu.pdf`。

---

## 0. 事前準備

| いつ | やること |
|---|---|
| 日程打診時 | **実際に面談を担当するCAに出てもらう**ことを明記する。管理者だけの参加になると、事前接触や結果報告の事故が現場で起きる |
| 前日 | スプレッドシートの編集権限が付与済みか、日程調整ツールのURLを受領済みかを確認。未了ならこの場で埋める |
| 開始前 | 該当領域のガイドURLとパスワードを手元に用意（チャットに貼るのは最後） |

**この場のゴールは2つだけ。**

1. 「面談前に本人へ直接連絡してはいけない」を、担当CA全員の頭に入れる
2. 「着座＝入室・応答」「結果報告は2営業日以内」を、CA自身の言葉で言えるようにする

残りは資料に書いてあるので、覚えて帰ってもらう必要はない。

## 2. 禁止事項スライドで必ずやること

このページだけは、聞き流されると事故になる。以下を口頭で確認する。

- 「**面談前にご本人へ連絡されることは、ありますか？**」と聞く
   - 「リマインドしています」と返ってきたら → **当社がやるので不要**と伝え、その運用を止めてもらう
   - 「紹介が難しい時は先にお伝えしています」と返ってきたら → **それが禁止対象**。まず窓口へ、に切り替えてもらう
- 違約金（利用料金の10倍または30万円のいずれか高い額）は、脅しではなく**過去に実際に辞退が発生したため条項化した**、という経緯まで話す

## 3. 想定質問

| 質問 | 回答 |
|---|---|
| 面談日程を変更したい | 原則お受けできません。貴社都合の変更・キャンセル・不参加・10分超の遅刻は、結果にかかわらず着座扱いです |
| 5分で終わってしまった面談も着座？ | 着座です。所要時間・完遂の有無・転職（就職）意欲は問いません |
| 求職者が20分遅れて入室した | 着座です。30分以内の入室・応答であれば成立します |
| 結果を入れ忘れた | 5営業日経過で自動的に着座扱い（みなし承認）になります。入力漏れは請求に直結するのでご注意ください |
| 明らかに紹介できない方が来た | 面談は実施してください。面談前にご本人へ伝えるのは禁止です。面談後に窓口へご共有ください |
| 請求対象外にしたい | 必ず**事前に**窓口へご連絡のうえ、エビデンスをご提出ください。シートに入力するだけでは受け付けられません |
| 送客を増やしたい／止めたい | 10営業日前までに窓口へ。SNS集客側の調整サイクルがあるため直前は反映が間に合いません |
| 面談担当を追加したい | 氏名・メールアドレス・日程調整ツールURLを窓口へ。最短翌営業日から反映します |
| 資料を社内で共有していい？ | ガイドは共通URL＋パスワードです。**貴社内の面談担当者に限って**ご共有ください |
